Each plan is self-contained: exact file paths, current code, target values, and
a feel check. An executor with no prior context should be able to run any one of
them without reading the others — except where the **Depends on** column says
otherwise.

## Recommended execution order

Run them in numeric order. The order is chosen so that no plan has to invent a
value a later plan would rename.

```
001 ──> 003 ──> 005        (index.html — must be sequential)
002 ──> 004                (app.js — must be sequential)
```

The two tracks are independent and touch different files, so 001→003→005 and
002→004 can proceed in parallel if two executors are available.

## Not planned

Findings that were confirmed but did not make the top five by leverage. Each is
real; none is urgent.

- **Notification dropdown asymmetry** (`app.js:10339`) — enters via the
  `ca-slide-down` keyframe, exits by hard unmount with no animation. Also has no
  `transform-origin` pointing back at the bell trigger and no scale component.
  Fixing properly means adding mount/unmount state to the component, which is a
  structural change rather than a motion tweak.
- **Modal backdrops hard-cut** (16 shells: `app.js:273`, `1127`, `2367`, `3559`,
  `4254`, `8065`, `10181`, `12110`, and others) — the panel animates in with
  `ca-scale-in` while the `bg-black/70` scrim appears instantly behind it. A
  ~150ms `ca-fade-in` on each backdrop would close the seam. Low risk, 16
  repetitive edits, no shared modal component to fix it in one place.
- **No stagger on card grids** — the roster (`app.js:4308`) and dashboard
  shortcut grids (`app.js:9863`) render 6–12 cards that all enter at once. A
  30–80ms stagger belongs here. Only two manual `animationDelay` values exist in
  the app today (`app.js:471`, `4575`).
- **Symmetric press timing on `Btn`** (`app.js:189`) — press and release both
  run at 150ms. Press is a deliberate act and can afford to be slower than the
  system's snap-back.

## Deliberate decisions left alone

These looked like findings and are not. Do not "fix" them.

- `index.html:93–101` — the `backwards`-vs-`both` choice on entrance animations,
  with a comment explaining that a lingering `transform` makes the element a
  containing block for `position: fixed` descendants, which broke modal
  centering. Correctly diagnosed; leave it.
- `index.html:85–90` — `.ca-pulse` runs a finite 3 iterations, not `infinite`,
  because a permanently pulsing badge becomes noise.
- `index.html:107–110` — the stated principle that ambient always-on motion is
  limited to the star twinkle, with everything else responding to user input.
- `app.js:4456–4459` — `TiltScene` gates on both `prefers-reduced-motion` and
  `hover: none`, and pauses while offscreen.
- `app.js:13331` — the quote carousel stops auto-advancing under reduced motion.
- `index.html:124` — the 0.9s hero title animation. Marketing surfaces are
  allowed a longer budget than UI; this is not a duration violation.
